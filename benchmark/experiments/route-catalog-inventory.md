# Route Catalog Inventory — полная база

`generated_at`: 2026-09-17T17:54:06Z

Инвентаризация каталога маршрутов (`knowledge-routes --write`) для полной
активной базы знаний. Приватность: отчёт содержит только агрегаты —
заголовки фактов, пути исходников и содержимое базы в репозиторий не входят.
Подробная детализация (с путями) — в локальном gitignored-файле
`benchmark/experiments/local/route-catalog-inventory.json`.

## Метод

1. `curator knowledge-routes --write` — генерация `<base>/knowledge-routes.md`
   (exit 0; существующего файла не было, бэкап не требовался).
2. `curator knowledge-routes --check` — актуальность каталога (exit 0,
   ошибок валидации нет).
3. Подсчёты — тем же кодовым путём, что и CLI: факты из SQLite-бэкенда
   (`query_facts`), маршруты через `build_routes`.
4. Оценка токенов каталога: `len(каталог) // 4` — тот же консервативный
   коэффициент, что в `delivery.py` (`_CHARS_PER_TOKEN = 4`).

## Критерии приёмки

- Каждый активный факт с `source_file` представлен ровно в одном маршруте —
  выполнено (104/104, непокрытых нет).
- Ни один deprecated-факт не является сигналом активного маршрута — выполнено
  (в базе 0 deprecated-фактов).
- Дубликатов source_file в маршрутах нет — выполнено (10 уникальных).
- Жёсткий бюджет первой версии 6000 токенов — выполнен: оценка 5415 ≤ 6000,
  разбиение по доменам не требуется.
- Каталог содержит только метаданные маршрутов (Description / When to use /
  Contains / Source): программная проверка не нашла в файле ни одного
  полного `content_summary` и ни одного фрагмента тела ≥ 40 символов.

## Расхождение DB ↔ Markdown (агрегаты)

Каталог строится из фактов SQLite-бэкенда, а база .md — человеко-читаемый
слой. Текущее состояние различается, маршруты это наследуют:

- 41 факт DB (в 3 файлах-источниках) не имеет соответствующих `###`-секций
  в текущих .md — человеко-читаемый слой отредактирован вручную.
- 24 `###`-секции в 5 файлах базы не представлены в DB.
- 20 .md-файлов базы вообще не имеют фактов в DB (ручные файлы), маршруты
  на них не указывают.

Решение о выравнивании слоёв (rebuild из .md или accept текущего DB как
источника истины) — вне этого эксперимента; отмечено для контроллера.
