# AGENTS.md

## Knowledge-скиллы проекта

Перед задачей проверь, не подходит ли один из скиллов. Скилл = файл
с правилом. При совпадении условий (when-to-use) — открой файл и примени
правило.

- **name:** suspend-dao-withcontext
  **description:** когда оборачивать вызовы в withContext, а когда нет
  **when-to-use:** пишешь suspend-функцию поверх DAO; видишь withContext вокруг suspend-вызова
  **source:** `kb/F72-withcontext-suspend-dao.md`

- **name:** retrofit-path-prefix
  **description:** пути API-методов не дублируют префикс base URL
  **when-to-use:** добавляешь API-метод в Retrofit-интерфейс
  **source:** `kb/F109-retrofit-path-prefix.md`

- **name:** dagger-intomap
  **description:** контрибуции в ViewModelFactory-карту требуют @IntoMap + ключ
  **when-to-use:** падение Unknown ViewModel; работаешь с ViewModelFactory
  **source:** `kb/F121-dagger-intomap.md`

- **name:** required-fields-no-orempty
  **description:** обязательные значения не маскируются заглушками
  **when-to-use:** ревью конструктора экрана; аргумент из route pattern
  **source:** `kb/F86-required-fields-no-orempty.md`

- **name:** textalign-viewstart-port
  **description:** порт XML-выравнивания на Compose без явного TextAlign
  **when-to-use:** переносишь TextView/XML-layout на Compose; выравнивание в LTR/RTL
  **source:** `kb/F68-textalign-viewstart-port.md`

- **name:** modifier-root-compose
  **description:** входной modifier один раз на корне composable
  **when-to-use:** пишешь composable-экран с входным modifier; инсеты/фон приходят извне
  **source:** `kb/F6-modifier-root-compose.md`
