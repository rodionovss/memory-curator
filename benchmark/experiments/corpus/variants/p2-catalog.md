# Каталог базы знаний (curator)

Тема задачи попадает в таблицу — найди знание через curator-инструменты:
вызови `curator_query` с search-строкой из последней колонки (curator query).

| Тема | Когда | curator query |
|---|---|---|
| Coroutines/DAO | пишешь suspend-функцию поверх DAO; видишь withContext | `withContext вокруг suspend DAO` |
| Retrofit | добавляешь API-метод; путь в @GET/@POST; base URL | `путь в Retrofit методе дублирует base URL` |
| Dagger | падение Unknown ViewModel; ViewModelFactory; multibindings | `Unknown ViewModel Dagger падение` |
| Валидация входа | ревью конструктора; route-аргументы; orEmpty | `orEmpty на обязательном поле` |
| Compose/RTL | переносишь XML-layout на Compose; выравнивание текста | `перенос textAlignment viewStart на Compose` |
| Compose/modifier | пишешь composable-экран; инсеты; фон корня | `входной modifier systemBarsPadding на корне` |

Тема задачи не попадает ни в одну строку — работай без базы знаний.
