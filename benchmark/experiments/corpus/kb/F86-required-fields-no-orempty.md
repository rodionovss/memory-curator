# Обязательные поля не маскируются заглушками

Обязательный параметр (например id из route pattern "detail/{id}") нельзя
превращать в пустое значение через orEmpty() или ?: "". Заглушка прячет
нарушение контракта в невалидное пустое состояние. Отсутствие обязательного
значения — явное падение (requireNotNull / error()), не дефолт.
