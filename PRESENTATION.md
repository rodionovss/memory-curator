# Memory Curator — защита проекта

**Hacker Sprint #2** · трек «Агент, который помнит» · команда: Сергей ([@rodionovss](https://github.com/rodionovss)), Егор ([@eger1393](https://github.com/eger1393))

Memory Curator — память агента, которая сама себя улучшает: извлекает
проверенные знания из сессий, отсекает мусор, раскладывает по структуре
документации и **меняет поведение агента** — правила памяти попадают в
контекст каждой сессии. 300+ тестов, установка одной командой.

## Измеренная дельта (48 прогонов, детерминированный скоринг)

10 задач-ловушек из реальных правил базы: агент **без** памяти применяет
правило 8/10, агент со **статичной** базой — 9/10, агент с **куратором**
(инжект правила) — **10/10**. На дискриминирующих задачах с репликацией
(N=3): **0/6 → 3/6 → 6/6, Fisher exact p = 0.0011**. Ключевой кейс: агент,
имевший всю базу из 66 фактов, повторил антипаттерн «как в соседнем коде»
во всех 3 повторах — доступность знания не равна его применению.
Методология и логи: [benchmark/application/](benchmark/application/) ·
[demo/before-after.md](demo/before-after.md)

## Проверить

### Быстро — 5 минут, только терминал

Нужно: `git`, Python 3.12+. opencode / Claude Code для быстрой проверки не нужны —
весь цикл жизни знания работает в CLI.

```bash
git clone https://github.com/podlodka-ai-club/refinement.git && cd refinement
./install.sh            # установка одной командой, ноль вопросов
curator demo --keep     # полный цикл: gatekeeper 7/3 → write-back → query →
                        # improve (дубликат, противоречие) → итог 5/0/2
curator status          # база, worker, последний improve

cd core && .venv/bin/python -m pytest tests/requirements/ -v
                        # 21 тест-требование, имя теста = ID требования
```

### Полный опыт — в opencode (здесь живёт основная часть продукта)

`install.sh` уже подключил всё сам: MCP-тулзы `curator_*`, 9 команд
`/curator-*`, правила памяти в глобальном AGENTS.md (база в контексте
каждой сессии), плагин-реминдер `session.idle`. Перезапусти opencode и:

- спроси агента «что в базе знаний?» → агент вызовет `curator_status` и ответит фактами
- закончи любую задачу → агент предложит `/curator-save` (правило из AGENTS.md)
- `/curator-create-map` — новые знания лягут по карте документации твоего проекта
