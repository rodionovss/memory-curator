# Трекер задач: локальные Markdown-файлы

Задачи и спецификации этого репозитория хранятся в виде Markdown-файлов в `.scratch/`.

## Соглашения

- Для каждой функции создаётся отдельный каталог: `.scratch/<идентификатор-функции>/`.
- Спецификация хранится в `.scratch/<идентификатор-функции>/spec.md`.
- Для каждой задачи реализации создаётся отдельный файл `.scratch/<идентификатор-функции>/issues/<NN>-<идентификатор>.md`. Нумерация начинается с `01`; объединять задачи в один файл нельзя.
- Состояние разбора указывается строкой `Status:` в начале файла задачи. Допустимые значения описаны в `triage-labels.md`.
- Комментарии и история обсуждения дописываются в конец файла под заголовком `## Комментарии`.

## Когда навык просит опубликовать материал в трекере задач

Создай новый файл в `.scratch/<идентификатор-функции>/`, при необходимости создав каталог.

## Когда навык просит получить связанную задачу

Прочитай файл по указанному пути. Обычно пользователь передаёт путь или номер задачи напрямую.

## Операции навигации

Эти правила использует `/wayfinder`. Карта представляет собой файл, которому соответствует отдельный дочерний файл для каждой задачи.

- **Карта**: `.scratch/<работа>/map.md` с разделами «Заметки», «Принятые решения» и «Неясности».
- **Дочерняя задача**: `.scratch/<работа>/issues/NN-<идентификатор>.md`, начиная с `01`, с вопросом в теле файла. Строка `Type:` содержит тип задачи (`research`, `prototype`, `grilling` или `task`), а строка `Status:` — состояние `claimed` или `resolved`.
- **Блокировки**: строка `Blocked by: NN, NN` в начале файла. Задача разблокирована, когда все перечисленные в ней файлы имеют состояние `resolved`.
- **Фронтир**: найди в `.scratch/<работа>/issues/` открытые, разблокированные и ещё не взятые задачи. Первой выбирается задача с наименьшим номером.
- **Взятие в работу**: установи `Status: claimed` и сохрани файл до начала работы.
- **Завершение**: добавь ответ под заголовком `## Ответ`, установи `Status: resolved`, затем добавь в раздел «Принятые решения» файла `map.md` указатель на контекст — краткую суть и ссылку.
