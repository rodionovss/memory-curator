# Статусы разбора задач

Навыки используют пять канонических ролей разбора. Эта таблица сопоставляет роли с фактическими строками статусов в трекере этого репозитория.

| Роль в mattpocock/skills | Статус в нашем трекере | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Ответственный должен оценить задачу |
| `needs-info` | `needs-info` | Ожидается дополнительная информация от автора |
| `ready-for-agent` | `ready-for-agent` | Задача полностью описана и готова для автономного агента |
| `ready-for-human` | `ready-for-human` | Требуется реализация человеком |
| `wontfix` | `wontfix` | Задача не будет выполнена |

Когда навык упоминает роль разбора, используй соответствующую строку статуса из этой таблицы.

Чтобы использовать другой словарь, измени правый столбец таблицы.
